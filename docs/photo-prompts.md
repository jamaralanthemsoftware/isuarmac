# Photo prompts for the ISU-ARMAC website

Each prompt below is complete, with the style and size already included. Copy the whole box into ChatGPT.

After generating, check every image for: extra or missing fingers, warped hands or tools, gibberish lettering on signs or clothing, and faces that look too perfect. Regenerate anything that fails.

**Replacing an image on the site:** in the CMS, open the page, double-click the block (Hero, Card or "Image and text"), upload the new file in the **Image** field, and fill in **Image description** (alt text, written for someone who can't see the image).
